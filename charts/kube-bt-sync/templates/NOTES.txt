1. Wait for the application:
   kubectl rollout status deployment/{{ .Release.Name }} -n {{ .Release.Namespace }}

{{- if eq .Values.app.service.type "NodePort" }}
2. Open the setup page:
   http://<node-ip>:{{ .Values.app.service.nodePort }}/setup
{{- else }}
2. Start a local port forward:
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ .Release.Name }}-svc 8080:{{ .Values.app.service.port }}
   Then open http://127.0.0.1:8080/setup
{{- end }}

3. Configure MySQL, Redis, PLATFORM_PUBLIC_URL and the Kubernetes connection in the setup wizard.

4. If the PVC remains Pending, set persistence.storageClass to a StorageClass returned by:
   kubectl get storageclass
