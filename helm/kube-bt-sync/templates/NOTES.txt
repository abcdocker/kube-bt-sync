1. 查看 Service：
   kubectl get svc -n {{ .Release.Namespace }} {{ include "kube-bt-sync.fullname" . }}

{{- if .Values.ingress.enabled }}
2. 在 DNS 或 /etc/hosts 中指向 Ingress 入口 IP，访问：
   http{{ if .Values.ingress.tls }}s{{ end }}://{{ (index .Values.ingress.hosts 0).host }}/
{{- else if eq .Values.service.type "NodePort" }}
2. 使用任意节点 IP + NodePort 访问控制台：
   http://<节点IP>:{{ .Values.service.nodePort }}
{{- else }}
2. 端口转发（临时）：
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "kube-bt-sync.fullname" . }} 8080:{{ .Values.service.port }}
   然后打开 http://127.0.0.1:8080
{{- end }}

3. 首次使用请打开 /setup 完成向导（或预先配置 Secret 中的 BAOTA_* 等环境变量）。

4. 数据目录：PVC {{ include "kube-bt-sync.fullname" . }}-data（若 persistence.enabled=true）。
